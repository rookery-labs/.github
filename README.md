# .github — Rookery Labs Organization Governance

This repository contains the global governance, organizational profile, issue templates, and pull request guidelines for **Rookery Labs**.

## Structure

- `profile/`: Contains the public GitHub organization profile README and ecosystem architecture map.
- `.github/ISSUE_TEMPLATE/`: Standardized issue templates requiring formal **Spec ID** references.
- `.github/PULL_REQUEST_TEMPLATE.md`: Mandatory pull request template requiring SDD spec links and TDD verification.
- `specs/`: Formal specifications for ecosystem governance, SDD contracts, and release standards.
